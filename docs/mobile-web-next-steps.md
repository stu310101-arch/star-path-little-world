# 手機 Web 優化交付（2026-10-10）

目標裝置是 iPhone 14／Safari，並降低較低階手機的下載與執行負擔。本次以第一階段 `bcf58ed`（`packs-60ebceee28b43f74`）為對照；最新建置為 `packs-0fc0108bad8a3346`。**沒有 iPhone／低階 Android 真機測量，不能宣稱全機型穩定 60 FPS。**

## 已完成的八個方向

1. **按需載入**：啟動只排入角色及其依賴；進入地區等待該區完成，鄰近地區在原本載入邊界前 12 個世界單位開始預取。音樂依場景請求，完整室內與完整中文字型延後。永久碰撞保留，下載失敗時停在安全的準備畫面，提供重新下載。
2. **角色記憶體與動畫資料**：維持 11 個材質 surface，改為逐材質去除重複／零形態鍵，避免每個零件承擔全身所有姿態。骨架、權重、頂點拓撲、材質及動畫時間保留；衣服位置採 1/16384 單位網格、法線採 1/4096 網格的有限精度表示，角色實際尺度的位置誤差上限 0.02 mm。這一步是有界精度縮減，不能稱為逐位元無損。原始 GLB／`.blend` 保留，原生遊戲繼續使用原始角色。
3. **獨立手機貼圖匯出**：Web Mobile 提供 ETC2，桌機保留 S3TC；入口先測實際 WebGL2 壓縮格式，再選擇版本。不支援 ETC2 時回到原有桌機包，避免只看 User-Agent 造成黑色貼圖。保留原貼圖尺寸與材質，手機不必額外下載桌機引擎／資源包。
4. **中文字型子集**：完整來源 11,941,968 B，靜態遊戲用字子集 389,056 B／625 字。保留中文字型輪廓、可變字重與排版資料。出現子集外、原字型支援的文字時才載入完整後備字型；失敗採有限次退避重試。原生字型不替換。
5. **下載峰值控制**：手機一次一個區域串流，完整包預留總額 64 MiB，已接收但未消費資料的高水位為 2 MiB。達門檻就等 Godot 消費後繼續；實際上限還包含一個瀏覽器回傳區塊。保留完整長度／SHA 驗證及壓縮回退，不將全部區域同時複製到 MEMFS。自訂快取分流也會等待較慢的消費者，快取配額失敗不阻塞遊戲。
6. **可選手機畫質及觸控**：「手機省電」將 3D 限在最高 960×540，UI 保持清晰；現有低配、一般及 30／60／90 FPS 選項保留，畫質切換不改玩家已選的幀率。新增移動搖桿、轉視角、奔跑、跳躍、互動及使用按鈕，接入既有遊戲輸入與相機規則；失焦會釋放按住的操作。
7. **較小的 Godot 引擎**：使用固定官方 Godot 4.7.2 原始碼編譯單執行緒模板，保留遊戲需要的 3D、物理、中文排版、音訊等模組。WASM 從 39,514,754 B 降至 34,245,266 B；實際交付 gzip 從 10,114,291 B 降至 8,742,725 B。來源、模組與重建方式見 [模板說明](../tools/templates/README.md)，loader 修改仍有 SHA 白名單防護。
8. **版本化離線快取**：Service Worker 以內容雜湊避免重複保存桌機／手機相同檔案，快取目標上限 128 MiB。小型入口檔先完整驗證；大型資源只隨實際請求保存。新版本等待舊分頁關閉才啟用，之後清除本站舊版本快取。快取不可用時仍走正常下載；已快取的起始區可離線重開。尚未下載／被瀏覽器清除的區域不能離線使用。這是離線資源快取，沒有加入安裝型 PWA 介面。

## 下載與記憶體數字

MB 使用十進位；下表是選用壓縮後的 PCK＋WASM HTTP body，未計 HTML／JS、HTTP 標頭與電腦小遊戲。下載量不等於裝置峰值 RAM。

| 項目 | 第一階段 | 本次 |
| --- | ---: | ---: |
| 引擎＋啟動包＋角色 | 72.69 MB | 手機 56.56 MB |
| 首次遊玩期間的 PCK＋WASM | 104.94 MB（當時等待全部室外包） | 本次手機流程觀測 66.85 MB，含已開始的櫻花區預取 |
| 角色資源包 | 36.81 MB | 28.90 MB（減少 21.5%） |
| WASM gzip | 10.11 MB | 8.74 MB |

只計角色、引擎、起始區與共享資源約 60.98 MB；再含總覽／起始區音樂約 62.30 MB。實際首玩量會受站點、等待時間、鄰區預取、既有快取與網路影響，不應把 56.56 MB 當成完整可遊玩的總下載量。這次記錄的 66.85 MB 比對照減少約 36.3%，仍未達到先前提出的 20–30 MB 目標。

手機模擬測試的下載暫存峰值為 **2,158,735 B（約 2.06 MiB）**，最大接收區塊 65,536 B，符合「2 MiB＋一區塊」限制。這只計 JS 區域下載暫存，**不含啟動解壓、WASM heap、MEMFS、Godot 資源、GPU 及瀏覽器記憶體**。PCK 掛載後仍保留到頁面結束，走遍所有區域的 RAM 負擔仍需真機驗收。

Chrome 155／RX 5700 XT，1920×1080 視窗、低配 3D 1152×720、60 FPS 上限、MSAA 關；同一條路線、真實鍵鼠輸入，兩版依序各跑三轮、每輪四秒。計數為有 WebGL 提交的 rAF 間隔，並非 GPU 完成時間或真機手機 FPS。

| 指標 | 第一階段 | 本次 |
| --- | ---: | ---: |
| 站立／轉視角 | 約 60 FPS | 約 60 FPS |
| 走路合併提交頻率 | 54.31 FPS | 55.92 FPS |

三輪走路分別為 53.21／59.35／50.41 與 50.30／58.51／58.98 FPS，兩版第一輪均含串流工作；量測區間均無大於 100 ms 的提交間隔。緩衝計數減少約 25.66 MiB，平均提交頻率略升但 P95 略差，不能宣稱所有卡頓都消失。此計數也不是完整 GPU／RAM 使用量。額外查看了實際 Web 跑步及跳躍畫面。

原始報告為 `mobile-before-low.json`、`mobile-after-low.json`。效能／手機遊玩測試使用 `packs-7797d62004a856b6`；最終發布只再加強快取失效寫入競態處理並整理原始碼說明／空白，Godot PCK、WASM、角色包等遊玩二進位與受測版本相同。快取生命週期另外驗證最終程式。

## 驗證

- 28 個 Python 封裝／壓縮／相依測試；58 個 Node 傳輸、壓縮、手機暫存、快取背壓及平台選擇測試。
- 瀏覽器完整遊玩 53 項：六區傳送、跨區步行、室內往返、畫質與 FPS、視窗縮放、重複載入與卸載。
- 手機輸入模擬 16 項：ETC2 分流、起始區 503 與重試、真實觸控搖桿／轉鏡、單次跳躍落地、540p 選項、暫存限制、斷網重開與設定保留。這項使用 Chromium／SwiftShader 支援 ETC2，**僅證明功能與格式路徑，不是 Safari 或手機 GPU 的效能結果**。
- Service Worker 真瀏覽器生命週期 9 項：離線回讀、驗證失敗清除快取、不完整更新拒絕啟用、舊分頁保持原版本、關閉後換版及舊快取清理；單元測試另外涵蓋配額提前失敗不阻塞下載。
- 練功區電腦遊戲 11 項：實際進房、坐下、開圍棋、落子及 AI 回應、關閉／重開保留對局。
- 原生畫質 66 項、長椅／入口 273 項、字型缺字後備與重試 7 項，另通過動畫採樣、分區、相機及分階段角色／室內準備檢查。長椅測試的兩個物理 tick 斷言前加入 `Input.flush_buffered_events()`，避免 headless 尚未派送合成按鍵；該測試退出仍有資源清理警告，不作執行時零洩漏證據。
- 7 個動畫共 42 組姿態：骨架／時間比對通過；原生渲染畫面對照共 145 個像素差異超過 8/255，最差單張平均差異 0.00196/255、最多 10 個明顯差異像素，差異集中於無 MSAA 的輪廓。已查看對照圖；未以純數值結果取代動作畫面檢查。

原始測量保留在本機 `deliverables/mobile-web/`、`deliverables/performance/`、`deliverables/movement-smoothing/` 及 `deliverables/web-optimization/avatar/`，未把大量截圖與逐幀資料加入 Git。測試腳本與可重建來源隨程式提交。

## 尚需真機驗收

用 iPhone 14／Safari、較低階 iPhone 及一台低記憶體 Android 分別測首次載入、重開、走跑跳、跨區、傳送、室內及連續遊玩 10–15 分鐘，確認頁面是否重載、材質、輸入與熱降頻。低階裝置可自行選手機省電和 30 FPS；本次沒有強制降低預設幀率。

若還要接近 20–30 MB 首玩，下一步需要進一步改造角色動畫的資源表示、縮小必需場景內容或更細的按需角色資源生命週期。這些需要新的外觀／動作與真機驗證；單純換 CDN 或增大快取不能解決執行時 RAM 和走路掉幀。

重建：安裝 Godot 4.7.2、匹配的匯出模板、Python NumPy／fontTools 與 Node 24+，執行 `python tools/build_web_release.py --godot <Godot-console> --node <Node> --local-only`。手機與桌機先各自驗證 PCK，再用 release manifest 驗證整組發布檔；未使用測試專用遊戲出口。
