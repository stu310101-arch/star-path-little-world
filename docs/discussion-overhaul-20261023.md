# 校園交流花園整體更新 — 2026-10-23

這輪更新涵蓋五區空間、道路、建築、植栽、材質、照明、水面、鏡頭、互動提示、導覽與載入／渲染管線。延續原先認可的留言裝置輪廓，保留五種材質與五區各自的建築特色。

## 遊玩體驗

- 五區向中心靠攏，廣場到入口由 29–31.8 m 縮短為 19.8–20 m，減少 31–38%。人、裝置、建築的尺度沒有隨之縮小。
- 加入北側 270°、寬 3.6 m 的環道，讓相鄰區直接相通。大學→科系、科系→高中生等代表路線，比新版仍經廣場的走法再短約 25–27%。南側仍經廣場，避開入口拱門。
- 五區共 40 座留言裝置各自保持固定地址。走近 2.8 m 內按 E 或「在此留言」操作，空裝置建立主留言，已有留言則閱讀主文／回覆。最近裝置以金色地面環提示。
- 將原本大型常駐底部面板改為位置資訊、可收合五區導覽與靠近時出現的操作卡。中央廣場有自己的名稱；390 × 844 手機版保留觸控活動空間。
- 重新調整第三人稱鏡頭、近裝置側移及障礙防穿。調整陽光、陰影偏移、天空、霧、材質亮度與水面；修正科系鋼架懸空與局部共面問題。

## 最低配置優化

| 環境三角形 | 962,594 | 499,232 | 273,068 |

三角形表不含角色、40 座裝置、UI 及 128 面鋼架補件。最低版依區域／材質合批；標準版保留空間分格。40 座裝置只合併靜態外觀的提交，碰撞、標籤、留言地址及操作仍獨立。最低／低檔選擇輕量環境，Web 最低檔不下載標準環境。

模型背景讀取、角色預載、碰撞與裝置分幀建立，降低載入時主執行緒停頓。貼圖共用並啟用實際 mipmaps，HUD 避免相同狀態重建，近距離查詢與可見範圍更新採固定時間間隔。

同一台 RX 5700 XT 的暖啟測量中，載入最大單幀由約 231–238 ms 降至 66–73 ms；五區固定活動位置由 152–166 draws 降至 100–136。中心因區域靠近，同時可見內容增加，最終 178 draws，仍高於原 160；曾出現的細分新版 319 draws 已消除。布局與構圖不同，不能把完整更新數據視為單一優化的隔離比較。

完整測量方法、原始數據與限制見 [渲染驗收](discussion-render-pipeline.md)。首次 GPU／shader 準備仍可能停頓，本輪未實測最低硬體或手機長時間溫度／幀率，不保證所有舊裝置無卡頓。

## 使用與來源

本機專案重新執行後即套用；已開啟的舊遊戲程序不會自動換場景。從大世界「校園生活誌」入口進入，走近裝置按 E；右上「五區導覽」選擇目的地。切換畫質會立即調整陰影等設定，環境植栽細節在下次進入花園套用。

可執行版本：`build/windows-discussion-overhaul-20261023/LittleWorld.exe`，同資料夾的 PCK／DLL 與授權文件須一起保留。輸出包含標準和最低環境，依遊戲內畫質設定選用。建置已核對模型來源 MD5、匯入場景 bytes、八支花園腳本、shader 與 layout SHA；封包防漏／過期檢查 12／12，Windows 主程序 headless 啟動及結束成功。另以 Godot console 對輸出 PCK 執行雙畫質場景驗證，各自建立五區、40 裝置與導航；此項不涵蓋 WebView，console 從另一個執行檔目錄啟動時無法解析 Windows 版放在主程式旁的 WRY DLL。正式登入與 WebView 沿用先前驗收，本輪未重測。

Blender 可編輯來源保留於 `art/DiscussionGarden/DiscussionGarden.blend`，原版備份在其 `history/pre-overhaul-20261023/`。現有 GLB 的四根科系支架由 `discussion_architecture.gd` 補上；重建源碼已同步，未來烘焙後會用 layout 旗標停用補件。標準／最低輸出均保留 UV、頂點色與材質。
