# 龍的 3D 方塊教學島

這是**全新、獨立**的 3D 體素風格新手小遊戲；不重用、不刪除、也不覆蓋原有導覽。

## 如何進入

正式登入並完成身分設定，進入星途世界後：

- 電腦：世界側欄按 **「🐉 龍的 3D 方塊教學」**。
- 手機：開啟 **☰ 選單**，再按同一按鈕。
- 右上角 **「返回星途」** 或 Esc（關卡與地圖都關閉時）會返回進入前的世界位置。共用的 IndoorTransition 保留世界實例，不重新建立世界。

教學的可操控角色是原創、用 Godot 方塊幾何組成的綠色 **像素龍**，包含方塊頭、角、眼、翅膀、背鰭、尾巴。無需下載額外 3D 素材；原本學士角色和其他場館素材均未更動。

## 操作與玩法

| 操作 | 桌面 | 觸控 |
| --- | --- | --- |
| 行走 | WASD | 左下方向按鈕 |
| 跑步 | Shift | 「跑」按住 |
| 跳躍 | Space | 「跳躍」 |
| 看周圍 | 按住滑鼠左／右鍵拖曳 | 在 3D 空白區拖曳 |
| 縮放 | 滾輪 | — |
| 互動 | 靠近發光方塊按 E | 「E 挑戰」 |
| 傳送／挑關 | M／教學地圖 | 「M 教學地圖」 |
| 切換近景／鳥瞰 | Tab | 地圖可直接傳送 |
| 返回起點 | Home | 地圖選第 1 站 |
| 關閉面板／返回星途 | Esc | 面板關閉鈕／「返回星途」 |

每個教學島展台有一個答題挑戰，答對領取一顆金色星星，最多 15 顆；第 1 關還需真的走 3 公尺、跳 1 次，第 2 關需真的拖曳旋轉鏡頭。其他展台練習的是**選擇正確操作方式**，不是直接操作實際帳號或服務。島上地圖可以立即跳轉到任一站，重玩已完成的題目不會重複累加。

## 15 站完整導覽

1. 走路、跑步、跳躍。
2. 視角拖曳、縮放、Tab 總覽。
3. 世界小地圖、完整地圖、六站、自然景點、櫻花林。
4. 靠近入口 E、場館切換、返回原位、Esc。
5. 星途登入與身分、共用帳號。
6. 我的成績、管理與選擇單份成績。
7. 興趣輔導室量表、報告與手動學類方向。
8. 落點分析室一般、APCS 與特殊工作台。
9. 選校研究所三桌、7:3／5:5／3:7 排序、校系收藏比較、F。
10. 大學館五區展廊、M 搜尋、J 收藏、模型近看與閱讀。
11. 校園生活誌五個主題區、留言、回覆、匿名選擇。
12. 練功區圍棋、單字王、E 坐下與 F／Enter。
13. 長椅、室內座位、書架、閱讀燈與可檢視展品。
14. 畫質、流暢度、音樂開關及音量。
15. 全部功能回顧、補課與安全返回世界。

## 資料與安全界線

- 關卡題目、星星與答題狀態**只存在這次教學場景的記憶體中**；重進即重新開始。沒有帳號登入表單、網路請求、資料同步或對真實成績／收藏／量表／留言／練習存檔的修改。
- 正式功能和介面以實際遊戲場館為準；教學是導覽與練習沙盒，並不替代正式功能的完整操作。
- 原版世界、學士角色、舊教學與相關服務都保留不變。
- 尚未將此分支部署到 Cloudflare 正式站，合併且重新匯出／部署後才會在線上出現。

## 驗證

使用 Godot 4.7.2（GL Compatibility）在儲存庫根目錄執行：

~~~sh
godot --headless --path game --script res://tests/pixel_tutorial_checks.gd
godot --path game
~~~

手動驗收應確認：桌面／觸控移動與跳躍、拖曳視角、15 個題目、錯誤答案提示、地圖傳送、按鍵 Esc、離開後仍保留原本世界位置和視角，以及帳號退出時沿用現有的鎖定機制。測試腳本為可執行的回歸檢查；**編寫它不等於已在本環境實際執行**。
