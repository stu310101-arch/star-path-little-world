    遊戲指南

    瞭解基本規則，開始你的第一局。

    1. 落子在交叉點

      黑棋先行，黑白輪流下一子。同色棋子沿上下左右相連成一塊，斜線相鄰不算相連。

    2. 氣與提子

      棋子旁邊上下左右的空點叫「氣」。落子後，對方整塊棋若沒有氣，就會被提走。不可下在使自己無氣的位置；若能先提掉對方而獲得氣，則可以落子。

    3. 棋局不可重複

      本遊戲採全局同形禁著：落子後不得重現本局曾出現的棋盤。停一手不受此限，悔棋則會退回對應歷史。

    4. 結束對局與計分

      沒有想下的位置時可「停一手」。連續兩次停著後會自動判斷黑白死子、移除計分並公布勝負。點選整塊棋可修正死子並立即重算；若仍有爭議，可返回對局。

    5. 以面積計勝負

      分數＝盤上活子＋只被己方包圍的空點；白棋另加 6.5 點。提子數不另外加分，共有空地不計。局面估算會先暫扣判出的死子；死活未定、劫爭與雙活需在結算時確認。
